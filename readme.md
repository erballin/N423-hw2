Purpose

This assignment will help you understand how to retrieve and display data. It will also focus on user feedback. Use this weather API if you would like.
Instructions

1. You need to understand how to retrieve and display data on a site for this assignment.
2. You will create an application that will get a JSON file and retrieve the needed data.
3. You will need to create the correct input boxes to get a city or zip code
4. You must style your entire page using SASS and make it look like a weather app.
5. You must have a login and signup button at the end of the four links.
6. Allow a user to see a set number of days in a forecast
7. You must incorporate over 80% of the information in the API JSON object.
8. Upload this to the Web 4 server and Github as well. Remember to add to your Readme file and put the link to Web 4 inside the Readme file.
9. Submit the Github link to this assignment. Links to an external site.
